2. OG description לא-defensible: קריטי

Your AI forgets everything when the session ends. infernoflow fixes that.

Every new AI session starts cold — the gotchas you found, the decisions you made, don't survive. infernoflow makes them stick.

3. חסר Bookmark feature: קריטי

ה־headline של v0.44.10 לא מופיע בכלל באתר! צריך feature card חדש:

🔖 Session bookmarks (New!)
Drop a named resume point mid-session. bookmark "before the SP refactor" auto-captures the current session transcript. Say "bookmark this" in chat and the Cursor hook does it for you. Never lose your place.

4. חסר Copilot LMT feature: קריטי

⚠️ תוקן 17/7/2026: הטענה המקורית כאן ("Copilot לא תומך ב־MCP") שגויה — Copilot Chat תומך ב־MCP מאז VS Code 1.102 (GA יולי 2025). הזווית הנכונה: dual transport — LMT בלי קונפיגורציה + MCP. הטקסט המוצע עודכן בהתאם.

🤖 Works with Copilot Chat — via LMT + MCP
infernoflow's VS Code extension registers amp_write / amp_read as native VS Code Language Model Tools — zero config, Copilot calls them on its own. Copilot Chat also supports MCP (VS Code 1.102+), and infernoflow init wires that too.

⚠️ שיפורים חשובים (P1) — 3 עדכונים

5. Feature "Auto-capture from git hooks" מטעה: חשוב

בפועל היום, ה־capture העיקרי הוא דרך amp_write MCP tool ו־Cursor hook (regex triggers). git hooks הם שני-שלישי.

🪝 Auto-capture from git hooks
Every commit is analyzed. Decisions, bug fixes, and WIP work are captured silently — no manual logging required.

🪝 Auto-capture via MCP + hooks
Your AI agent calls amp_write directly through MCP — gotchas, decisions, and failed attempts get logged as you work. A Cursor beforeSubmitPrompt hook backstops the AI with deterministic regex triggers (!!, retry, bookmark this). Optional git hook for commit messages too.

6. Feature "Capability contracts" - כבר לא רלוונטי: חשוב

ב־v0.44.0 חתכת ~9000 LOC של ה־contract layer. כתוב באתר "infernoflow tracks what your codebase can do" — אבל זה לא ה־focus יותר.

🔍 Capability contracts
infernoflow tracks what your codebase can do — not just what it contains.

🌿 Branch-aware memory
Memory routes into .ai-memory/branches/<branch>.jsonl — travels with git. Switch branches, your AI sees the right context. Teammates inherit your memory by checking out your branch.

7. MCP tools list מיושן: חשוב

"implement, check, review, synthesize" — כל אלה שמות ישנים מ־v0.43. השמות הנוכחיים הם amp_* + infernoflow_*.

📡 MCP server included
Ships with MCP tools your AI calls automatically: implement, check, review, synthesize, and more.

📡 10 MCP tools included
Ships with tools your AI calls automatically: amp_write, amp_read, amp_search, amp_bookmark, amp_handoff, amp_health, plus four infernoflow_* helpers. Zero configuration.
